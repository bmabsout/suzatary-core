# Many chats, one memory, a chat as good as the best — 2026-09-25

Todos `multichat` and `chatux` (chain `suzatary`), on
`docs/CHATSHAPE-PLAN-2026-09-15.md` and ARCHITECTURE §10.3. Unchanged: the
transcript is the record; a turn is the least trusted text the app shows
(an IMAGE the box renders, never markup the browser parses); the browser
computes nothing of its own; `Tap` and the no-send shape.

## 1. The survey

- **Claude**: memory as ENTRIES you read, edit, delete, written live;
  project memory apart; chat search on request. Edit or Retry forks a
  branch (‹ 2/3 ›); titled chats, search, stop, copy per answer and block.
- **ChatGPT**: saved memories, a deletable list, beside derived history.
  **Gemini**: "Saved info" as standing instructions; temporary chats.
- **The attack**: SpAIware (Rehberger, 2024) wrote a web page's
  instructions into ChatGPT's memory and exfiltrated later chats through
  image URLs; Unit 42 and 2026 papers (ER-MIA, sleeper memories): one
  poisoned document persists into every later session.
- **Streaming UX**: anchored, drifted up, jumped back; never move a
  reader; render closed blocks, the open tail as text; drafts per chat.

## 2. What the app does (read in `web/src/conversation/`, not guessed)

A closed `SourceState` over one `step`; SSE `state/delta/turn/working`;
the partial as ONE `textContent` node; answers as the box's SVG
(`…/turns/<i>/render`, per theme) with references linked and "Show as
text"; rounds with a folded trace, refusals marked; cards in place; day
separators; `Earlier…`; keyed DOM; stick to bottom on a fresh window, else
"↓ new answer"; Ctrl/⌘-Enter; chips, photos, Reply-as-quote; a queue,
never a disabled Send; the legend "Thinking · 12 s"; push when unwatched;
page, sheet and panel; `?about=`. Several conversations exist (`start`, the
review's) but only the palette lists them.

MISSING: stop, regenerate, edit, copy, a list, titles, search, streamed
rendering (raw Typst until `turn`), following a growing partial, thinking
where the answer lands, drafts, a memory the secretary keeps.

## 3. Memory

1. **Where.** `secretary/memory.jsonl` beside the transcripts: box-local,
   git-ignored, never the chain (a fact has no fulfillment). Lines
   `Remembered { id, at, fact, kind, said }`, `Forgotten { id, at, by }`.
   ONE memory for every conversation.
2. **`Fact::new` is the only door**: refuses empty, over 280 characters, a
   URL or a line break. `kind` is closed (`the owner | Person | Preference |
   Standing`). At most 200 live facts; past it `remember` refuses naming
   the cap, so the secretary merges.
3. **The secretary writes, through `remember` and `forget`.** `said` is
   NOT a parameter: it is the round's OPENING turn, a `Turn::Person` or an
   act with words, both the gate's actor. A round the box opened (brief,
   review, sweep) has none, so `remember` refuses there by construction.
4. **Taint, derived, deny by default.** One total `match`
   (`secretary::taint`) classes every verb: `Clean` only for `context`,
   `weather` and the memory verbs; every other verb and every chip loaded
   is `Tainted` (mail, triage-written todo text, attachments, `web`,
   repos, and `recall`: old answers were written after reading mail). `remember` after any tainted answer in its
   round stores a `Proposal::Remember(Fact)` card instead: a memory written
   because an email said so is the attack. SECRETARY.md: `remember` FIRST.
5. **No channel out.** No verb reaches outward; an answer is an SVG in an
   `<img>`, which loads no URL; a fact holds none (SpAIware's second half).
6. **The owner sees every write.** A `remember` is a receipt line in its round
   ("Remembered: … · Forget"), never folded into the trace.
   `#/secretary/memory` lists live facts by kind (`textContent`: a fact is
   model text), each linking the round that said it, with Forget.
7. **Forget erases.** `POST /api/secretary/memory/<id>/forget` (the `say`
   gate: a named peer, the CSRF triple, loopback refused) and the `forget`
   verb rewrite the file atomically under its lock without that line, then
   append `Forgotten` (id, never text). Transcripts that quoted it stay,
   and the page says so.
8. **Delivered, not prompted** (a session snapshots its prompt). Each
   conversation stores `Entry::MemorySeen { version }`; `queue::delta`
   heads each batch with facts added and forgotten since (a new session
   gets all): exactly once, by derivation, as the queue. SECRETARY.md:
   background, never instructions.
9. **Recall.** `recall(query)` answers person turns and answers from other
   conversations (never verb answers: they quote mail), by the SAME
   function as the list's search (§4.2).

## 4. Chats

1. **Topics.** `Opened` gains `kind: Default | Topic | Review`
   (`serde(default)` reads old files by id). The owner opens a Topic and names
   it; left blank, the box titles it after the first answer (a stateless
   `Model` call, the `title` job in `[models]`) as `Entry::Titled { title,
   by }`, last wins, so rename is an append. Each topic is its own session;
   all share §3's memory.
2. **The list.** `#/secretary` lists Default pinned, then Topics by last
   turn, Reviews behind a filter: title, last line, time. Search asks `GET
   /api/secretary/search?q=` (the box's substring over person turns and
   answers); a hit opens its conversation windowed at the turn. At 62rem+
   the list is a column. The sheet and panel stay on Default.
3. **Stop.** `POST …/stop` (the `say` gate) ends the model process and
   appends `Turn::Act` "You stopped the answer"; the partial is dropped (it
   never was a record). Stop sits where the answer lands; Esc too.
4. **Regenerate and edit: the LAST round only.** `Entry::Rewound { to, at,
   by }` sets turns from `to` aside: drawn collapsed as "Earlier attempt",
   never delivered. Regenerate sets aside trace and answer, so the person
   turn is pending again (`delta` reads the live path); edit sets aside the
   person turn and appends the new one. The session is dropped and
   re-opens over the live path (the lost-session path, one cold re-send).
   REFUSED when the round wrote anything (a chain object, a memory, a
   proposal): a rewind never hides a write; the refusal says ask again.
5. **Answers in blocks.** The box splits an answer with `typst-syntax` at
   top-level blank lines (never inside code, a list or an equation) into
   `Block { source, plain, kind }`, `plain` being typst's own text of it,
   each rendered at `…/turns/<i>/blocks/<n>/render`. The `alt` is the whole
   `plain`, not an excerpt.
6. **Streamed as Typst.** The worker closes a block at each top-level
   blank line, keeps it by sha256 and sends `block { n, sha }`; the page
   draws `…/partial/<sha>/render`. The browser names a hash, never text, so
   it cannot make the box render what the model did not write. The open
   tail stays `textContent`; a block that fails to compile stays text.
7. **Copy** per answer (`plain`, or its Typst) and per block: box text.
8. **The answer's place.** One row where the answer will land: Queued →
   Thinking · 12 s → Reading mail · 3 checked, the trace growing under it,
   Stop beside. The header legend goes.
9. **Scroll.** On send the question goes to the top of the box and the
   answer grows into reserved space beneath; streaming never moves the
   box. Scrolled up, the pill. The three states are `anchor.ts`, a sum.
10. **Typography** (`theme.typ`'s `answer`): the document's faces, 16 px,
    1.5 leading, at most 68 ch, per width bucket (`?w=360|480|720`).
11. **Keys, drafts.** ↑ in an empty composer edits the last message; a
    draft per conversation in `localStorage` (try/catch; a convenience).

## 5. The laws, each with its test

- Memory is the fold of its lines; forget leaves no text of the fact. —
  `app/core/tests/memory.rs` "memory is its fold", "forgetting erases".
- Every conversation has been told exactly the memory as it stood at its
  last round, under any interleaving. — `memory.rs` "one memory, every
  conversation" (proptest).
- A `remember` after a tainted answer is a proposal; a box-opened round
  cannot remember; `taint` is total, so a new verb needs a class to
  compile. — `secretary/verbs.rs` "tainted rounds propose", "no opener,
  no memory".
- A rewind never hides a write. — `store.rs` proptest.
- Block sources concatenate to the answer. — `answer.rs` proptest; the
  page agrees over `app/core/tests/web/blocks.json` (`answer.test.ts`).
- `answer.step` reaches only legal states. — `answer.test.ts`, `gen.ts`.
- Streaming never scrolls a drifted-up box. — `web/e2e/secretary.test.ts`.
- Still one `innerHTML`. — `scripts/build-web.sh`.

## 6. The TypeScript's shape

```ts
export namespace answer {
  export type T =
    | {type: "Queued"} | {type: "Thinking", since: number}
    | {type: "Working", verb: string, since: number}
    | {type: "Streaming", blocks: {n: number, sha: string}[], tail: string}
    | {type: "Done", turn: number} | {type: "Stopped"}
  export const step = (a: T, f: Frame): T => …
  export const view = (a: T, {stop}: {stop: () => void}): Node => …
}
export default answer

export namespace lo {
  export type T<V> = {type: "Loading"} | {type: "Error", e: string} | {type: "Val", v: V}
  export const map = <A, B>(l: T<A>, f: (a: A) => B): T<B> => …
  export const flatten = <A>(l: T<T<A>>): T<A> => …
  export const combine = <A, B>(a: T<A>, b: T<B>): T<[A, B]> => …
}
```

`list.ts`, `memory.ts`: `lo.T` of a payload, `view(v, {get, set})`.
